# 光学折射模拟器（基于 Python + Tkinter）

## 一、 项目设计思路

在学习光学时，斯涅耳定律（n₁sinθ₁ = n₂sinθ₂）虽然公式简单，但光线在不同介质中传播时的偏折过程非常抽象。为了将抽象的物理公式转化为直观的视觉体验，我决定开发一个交互式光学折射模拟程序。

核心思路：
1. 输入参数：用户在界面上输入介质折射率（n2）和入射角（θ1）。
2. 物理计算：程序基于斯涅耳定律，自动计算折射角（θ2）。
3. 可视化绘制：利用 Tkinter 的 Canvas 在界面上绘制分界面、法线、入射光线和折射光线，并在画布上标注出角度。

## 二、 核心功能

- 支持用户输入介质折射率（默认 1.5，模拟玻璃）。
- 支持**滑块拖动**调节入射角（0°~89°），并在右侧实时显示当前的精确入射角。
- 支持**精确输入入射角**，可通过输入框手动输入角度并更新。
- 在画布上实时绘制光路，入射光线（蓝色）从空气进入介质，折射光线（红色）在介质中偏折。
- **数据校验与容错**：程序内置了 try-except 机制，防止用户输入非法数据导致崩溃。

## 三、 开发过程与遇到的问题（核心部分）

在这个项目开发中，我遇到了几个实际困难，并通过查阅文档和独立思考逐一解决了：

**问题 1：物理角度与屏幕像素坐标的转换**
- **遇到问题**：物理公式给的是角度，但计算机绘图是以像素为单位的（x, y 坐标）。第一次写完后，光线要么是反的，要么射线超出了画布。
- **解决思路**：我通过分解三角函数（正切 tan）来解决。入射光线从左侧边缘（start_x = 50）出发，利用 `start_y = cy - (cx - start_x) * math.tan(theta1_rad)` 来反向计算 y 坐标。同理，折射光线从入射点向右下方延伸，利用 `end_y = cy + (end_x - cx) * math.tan(theta2_rad)` 计算终点。通过调整正负号，最终让光线方向完全正确。

**问题 2：用户输入非法数据导致程序崩溃**
- **遇到问题**：最初，如果用户不小心在“介质折射率”输入框里输入了字母，或者输入了 0 或负数，运行 `float()` 转换或进行除法时会直接报错，整个程序闪退。
- **解决思路**：我引入了 Python 的 `try-except` 异常捕获机制。在 `update()` 方法中，我尝试将输入框内容转换为浮点数并判断是否大于 0；如果出错，就在 `except` 代码块中将折射率重置为默认的 1.5，并刷新输入框。这就保证了无论用户怎么乱输入，程序都不会崩溃。

**问题 3：精确输入与滑块更新的冲突**
- **遇到问题**：为了精确控制角度，我加了一个文本框，同时保留了滑块。一开始，如果我在文本框里输入数字后，直接去点“更新”按钮，角度经常不同步；如果在文本框里输入了 90 度，滑块调不过来。
- **解决思路**：我单独为文本框编写了 `angle_entry_update` 方法。首先对用户输入进行边界处理（<0 时设为 0，>89 时设为 89），然后通过 `self.slider.set(val)` 直接控制滑块，最后统一调用 `self.update()` 刷新图像。这样两个输入控件就完美同步了。
